# Penalty Kick Game

A simple penalty kick game built with Vite and vanilla JavaScript for JavaScript Advanced Assignment 4.

## Features

- Move the ball with the arrow keys
- Shoot with Space or the Shoot button
- Random GOAL, SAVED and MISS results
- Confetti effect when scoring a goal
- Responsive layout

## Technologies

- Vite
- HTML
- CSS
- JavaScript
- canvas-confetti
